## 🧭 2. **Nuremberg Numbering System (Dot-Delimited Hierarchy)**

A dot-delimited system is used to express **parent-child** relationships, like:

```
1.13.2.4.1  → Pillar 13 (Engineering), subdomain 2 (Civil), sub-subdomain 4 (Mining), concept 1 (Open-pit mining)
```

This structure **mirrors legal outlines or military organizational codes**, e.g.:

```
Title 40.4.3.2 – Clean Water Act → Section → Subsection → Clause
```

This hierarchical structure allows **any node to be addressed precisely** — across all knowledge dimensions.

## 🧾 3. **SAM.gov-Compatible Naming Conventions**

**SAM.gov** defines naming patterns for federal regulations, procurement codes, agency IDs, and project metadata.

The UKG system aligns with SAM.gov via:

| Element         | SAM.gov Format          | UKG Mapping          |
|----------------|--------------------------|----------------------|
| **NAICS**       | 6-digit code (e.g. 212319) | Axis 2 (Sector)       |
| **PSC**         | 4-letter code (e.g. F999) | Axis 2.4 or Axis 6    |
| **Entity IDs**  | UEI/DUNS/NCAGE           | Meta-tags (in Axis 5 or 12) |
| **Program Tags**| e.g. “EPA.NEPA.303(d)”   | Axis 6.101.4.303      |

Each node in the graph may be **annotated** with SAM.gov tags — these form part of the **naming schema** within the metadata (`M(t)` in the graph state model).

For example:

```

→ 101: EPA
→ 4: NEPA regulatory layer
→ 303: Section 303(d) of the Clean Water Act
```

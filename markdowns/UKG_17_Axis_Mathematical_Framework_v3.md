## 3. Distance Metrics and Similarity Functions

### 3.1 Euclidean Distance in 17D Space

Standard Euclidean metric:

```
d_euclidean(K₁, K₂) = √(Σᵢ₌₁¹⁷ (k₁ᵢ - k₂ᵢ)²)

Normalized version:
d_normalized = d_euclidean / √17
```

### 3.2 Weighted Manhattan Distance

Accounting for variable axis importance:

```
d_manhattan(K₁, K₂) = Σᵢ₌₁¹⁷ wᵢ × |k₁ᵢ - k₂ᵢ|

Where wᵢ = context-dependent axis weight
Σwᵢ = 1 (normalized weights)
```

### 3.3 Mahalanobis Distance

Context-aware distance incorporating correlations:

```
d_mahalanobis(K₁, K₂) = √((K₁ - K₂)ᵀ × Σ⁻¹ × (K₁ - K₂))

Where:
Σ = 17×17 covariance matrix capturing inter-axis relationships
Σ⁻¹ = inverse covariance (precision matrix)

Advantages:
- Accounts for axis correlations
- Scale-invariant
- Better for non-isotropic distributions
```

### 3.4 Cosine Similarity (Semantic Emphasis)

Primarily for semantic/knowledge axis:

```
similarity_cosine(K₁, K₂) = (K₁ · K₂) / (||K₁|| × ||K₂||)

Where:
· = dot product
|| || = Euclidean norm

Range: [-1, 1]
1 = identical direction
0 = orthogonal
-1 = opposite direction
```

### 3.5 Custom UKG Hybrid Distance

Optimized composite metric for 17-axis system:

```
d_UKG(K₁, K₂) = α·d_euclidean(K₁, K₂) + 
                 β·(1 - similarity_cosine(K₁, K₂)) + 
                 γ·d_mahalanobis(K₁, K₂) + 
                 δ·temporal_distance(k₁₁, k₂₁)

Constraints:
α + β + γ + δ = 1 (normalized weights)
All terms scaled to [0, 1]

Default weights:
α = 0.25 (Euclidean)
β = 0.35 (Cosine, emphasis on semantic)
γ = 0.25 (Mahalanobis)
δ = 0.15 (Temporal)

Temporal distance with decay:
temporal_distance(t₁, t₂) = 1 - exp(-λ|t₁ - t₂|)
λ = decay constant (domain-dependent)
```

### 5.4 Graph Traversal Algorithms

**Breadth-First Search (BFS):**
```python
def BFS(start_node, depth_limit=5):
    queue = [(start_node, 0)]
    visited = {start_node}
    result = []
    
    while queue:
        current, depth = queue.pop(0)
        result.append(current)
        
        if depth >= depth_limit:
            continue
            
        for neighbor in current.neighbors:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, depth + 1))
    
    return result

Time Complexity: O(V + E)
Space Complexity: O(V)
```

**Depth-First Search (DFS):**
```python
def DFS(node, target_condition, path=[], max_depth=10):
    if len(path) >= max_depth:
        return None
        
    if meets_condition(node, target_condition):
        return path + [node]
    
    for child in node.children:
        result = DFS(child, target_condition, path + [node], max_depth)
        if result:
            return result
    
    return None

Time Complexity: O(V + E)
Space Complexity: O(depth)
```

**Dijkstra's Shortest Path:**
```python
def dijkstra(graph, start, end):
    distances = {node: float('inf') for node in graph.nodes}
    distances[start] = 0
    priority_queue = [(0, start)]
    predecessors = {}
    
    while priority_queue:
        current_dist, current_node = heappop(priority_queue)
        
        if current_node == end:
            break
            
        if current_dist > distances[current_node]:
            continue
            
        for neighbor, weight in graph.edges[current_node]:
            distance = current_dist + weight
            
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                predecessors[neighbor] = current_node
                heappush(priority_queue, (distance, neighbor))
    
    return reconstruct_path(predecessors, start, end)

Time Complexity: O((V + E) log V) with binary heap
Space Complexity: O(V)
```

### 5.5 Centrality Measures

**Degree Centrality:**
```
C_degree(v) = deg(v) / (n - 1)

deg(v) = number of edges incident to v
n = total number of nodes

Interpretation: Fraction of nodes directly connected
```

**Betweenness Centrality:**
```
C_betweenness(v) = Σ_{s≠v≠t} (σ_st(v) / σ_st)

σ_st = total shortest paths from s to t
σ_st(v) = shortest paths from s to t through v

Interpretation: Bridge nodes in network
```

**PageRank:**
```
PR(v) = (1-d)/n + d × Σ_{u∈M(v)} PR(u) / L(u)

d = damping factor (typically 0.85)
M(v) = set of nodes linking to v
L(u) = number of outbound links from u
n = total nodes

Iterative calculation until convergence:
PR^(t+1)(v) = (1-d)/n + d × Σ_{u∈M(v)} PR^(t)(u) / L(u)
```

## 10. Multi-Agent Consensus Algorithms

### 10.1 Byzantine Fault Tolerant (BFT) Consensus

```
BFT_Consensus(responses, max_faulty=1):
    n = len(responses)
    f = max_faulty
    
    # Require n ≥ 3f + 1
    assert n >= 3*f + 1
    
    # Need 2f + 1 matching responses
    threshold = 2*f + 1
    
    # Group by value
    groups = group_by_value(responses)
    
    for value, group in groups:
        if len(group) >= threshold:
            return {
                consensus: value,
                support: len(group),
                confidence: len(group) / n
            }
    
    return NO_CONSENSUS

Typical configuration:
n = 4 personas
f = 1 (tolerate 1 faulty agent)
threshold = 3 (need 3/4 agreement)
```

### 10.2 Weighted Voting

```
Weighted_Vote(responses, weights, confidences):
    total_weighted = 0
    total_weight = 0
    
    for i, response in enumerate(responses):
        effective_weight = weights[i] × confidences[i]
        total_weighted += response × effective_weight
        total_weight += effective_weight
    
    consensus = total_weighted / total_weight
    
    # Variance measure
    variance = Σᵢ (wᵢ × cᵢ × (rᵢ - consensus)²) / total_weight
    strength = 1 / (1 + variance)
    
    return {
        value: consensus,
        strength: strength,
        participating_weight: total_weight
    }
```

### 10.3 Debate-Based Iterative Refinement

```
Debate_Consensus(agents, query, max_rounds=5):
    # Round 0: Initial responses
    responses = {a: a.generate(query) for a in agents}
    
    for round in range(1, max_rounds + 1):
        # Critique phase
        critiques = {}
        for agent in agents:
            others = {a: r for a, r in responses.items() if a != agent}
            critiques[agent] = agent.critique(others)
        
        # Revision phase
        new_responses = {}
        for agent in agents:
            agent_critiques = [c[agent] for c in critiques.values()]
            new_responses[agent] = agent.revise(
                responses[agent],
                agent_critiques
            )
        
        # Convergence check
        convergence = calculate_convergence(responses, new_responses)
        responses = new_responses
        
        if convergence > 0.95:
            break
    
    return synthesize(responses)
```

### 10.4 Confidence-Weighted Consensus

```
Confidence_Consensus(responses):
    values = [r.value for r in responses]
    confidences = [r.confidence for r in responses]
    
    # Softmax weighting
    exp_conf = [exp(c) for c in confidences]
    weights = [e / sum(exp_conf) for e in exp_conf]
    
    # Weighted consensus
    consensus = sum(w * v for w, v in zip(weights, values))
    
    # Agreement factor
    agreement = 1 - (std_dev(values) / max(mean(values), 0.001))
    
    # Final confidence
    final_conf = max(confidences) × agreement
    
    return {
        consensus: consensus,
        confidence: final_conf,
        weights: weights
    }
```

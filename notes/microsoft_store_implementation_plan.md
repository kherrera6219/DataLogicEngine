## Phase 3: User Data Rights Implementation (Days 7-12)
**Priority:** 🔴 Critical | **Effort:** Medium | **No External Dependencies**

### Deliverables
1. User data export endpoint
2. User data deletion endpoint
3. Privacy & Data settings page
4. "My Data" dashboard

### Implementation

#### 3.1 Create User Data Routes
**File:** `routes/user_data_routes.py` (NEW)

Endpoints:
- `GET /api/v1/user/data/export` - Export all user data (JSON/CSV)
- `POST /api/v1/user/data/delete` - Request account deletion
- `GET /api/v1/user/data/categories` - List data categories collected

Features:
- Collects user profile, trace runs, chat messages, audit logs
- Supports JSON and CSV export formats
- 30-day grace period for deletion
- Audit logging of all data access

#### 3.2 Create Privacy Settings Page
**File:** `frontend/app/settings/privacy/page.tsx` (NEW)

Features:
- Display all data categories collected
- "Download My Data" buttons (JSON/CSV)
- "Delete My Account" with username confirmation
- Link to privacy policy
- Warning about deletion consequences

#### 3.3 Register Routes
**File:** `backend/__init__.py`

Add blueprint registration:
```python
from routes.user_data_routes import user_data_bp
app.register_blueprint(user_data_bp)
```

## Phase 5: Accessibility Testing & Fixes (Days 17-20)
**Priority:** 🟡 High | **Effort:** Medium | **No External Dependencies**

### Deliverables
1. Automated accessibility audit
2. Keyboard navigation verification
3. Screen reader testing
4. Color contrast fixes

### Implementation Steps

1. **Install Testing Tools**
```bash
cd frontend
npm install -D @axe-core/cli lighthouse
```

2. **Run Automated Audits**
```bash
npm run dev
npx @axe-core/cli http://localhost:3000
npx lighthouse http://localhost:3000 --only-categories=accessibility
```

3. **Manual Testing Checklist**
- [ ] Tab through all pages (verify focus indicators)
- [ ] Test with NVDA/JAWS (Windows) or VoiceOver (Mac)
- [ ] Verify all images have alt text
- [ ] Check color contrast ratios
- [ ] Test keyboard shortcuts
- [ ] Verify form labels

4. **Common Fixes**
- Add missing `aria-label` attributes
- Ensure proper heading hierarchy
- Add focus indicators where missing
- Fix color contrast issues
- Add skip links where needed

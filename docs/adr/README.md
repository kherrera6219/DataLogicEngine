# Architecture Decision Records (ADR)

## Purpose

Capture high-impact technical decisions with context, alternatives, and consequences.

## Index

1. `ADR-0001-engineering-governance-baseline.md`

## Authoring Rules

1. One decision per ADR file.
2. Use immutable ADR IDs (`ADR-0001`, `ADR-0002`, ...).
3. Do not rewrite historical context after acceptance; add superseding ADRs instead.
4. Link ADRs from implementation PRs and relevant docs.

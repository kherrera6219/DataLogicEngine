# Desktop Deployment Guide

> **DEPLOYMENT MODE**: This guide is for **Desktop Mode** only (Windows-native) installation.  
> For cloud deployment, see `DEPLOYMENT_CLOUD.md`.  
> These are **mutually exclusive modes** - do not attempt to run both simultaneously.

## Overview
This guide covers deploying the DataLogicEngine Windows desktop application with the integrated "Zero-Login" identity system.

---

## Pre-Deployment Checklist

### System Requirements
- **OS**: Windows 10/11 (64-bit)
- **Memory**: 8GB RAM minimum, 16GB recommended
- **Storage**: 2GB free space for application + dependencies
- **Privileges**: Administrator access for initial installation

### Required Dependencies (Auto-Installed)
- PostgreSQL 15.x (installed to `C:\Program Files\PostgreSQL\15`)
- Redis (Memurai) (installed via silent installer)
- .NET Framework 4.8+ (for WinSW service wrapper)

---

## Installation Steps

### 1. Prepare Distribution Package

Ensure you have the complete distribution structure:

```
dist_package/
├── backend/                    # PyInstaller output
│   └── DataLogic_Backend.exe
├── frontend/                   # Next.js standalone
│   ├── .next/
│   ├── server.js
│   └── package.json
├── scripts/
│   └── windows/
│       ├── install.ps1         # Main installer
│       ├── setup_db.ps1        # PostgreSQL setup
│       ├── setup_cache.ps1     # Redis setup
│       ├── backup_data.ps1     # Backup script
│       └── uninstall.ps1       # Uninstaller
├── services/                   # WinSW XML configs
│   ├── UKG-Backend.xml
│   ├── UKG-Frontend.xml
│   └── winsw.exe
└── migrations/                 # Database migrations
```

### 2. Run Installation Script

Open PowerShell as **Administrator**:

```powershell
cd C:\path\to\dist_package\scripts\windows
.\install.ps1 -InstallPath "C:\Program Files\DataLogicEngine"
```

**What This Does**:
1. ✅ Creates installation directories
2. ✅ Installs PostgreSQL with hardened configuration
3. ✅ Installs Redis (Memurai)
4. ✅ Runs database migrations (`flask db upgrade`)
5. ✅ Registers Windows services (`UKG-Backend`, `UKG-Frontend`)
6. ✅ Configures nightly backup task

### 3. Verify Services

Check service status:

```powershell
Get-Service UKG-* | Format-Table Name, Status, StartType
```

Expected output:
```
Name           Status StartType
----           ------ ---------
UKG-Backend    Running Automatic
UKG-Frontend   Running Automatic
UKG-Postgres   Running Automatic
UKG-Redis      Running Automatic
```

### 4. First User Access

Navigate to `http://localhost:3000`

**First Run Behavior**:
- System detects no existing users
- Current Windows user (SID) auto-registered as **Owner**
- No login required - authenticated via Windows session
- Owner sees full administrative interface

## Configuration

### Environment Variables

Edit `C:\Program Files\DataLogicEngine\backend\.env`:

```env
# Database (auto-configured)
DATABASE_URL=postgresql://ukg_app:ukg_local_pwd@localhost:5433/ukg_local

# Security
SECRET_KEY=<auto-generated>
ENCRYPTION_KEK_SECRET=<auto-generated-on-first-run>

# Services
FLASK_ENV=production
LOG_LEVEL=INFO
```

### Port Configuration

Default ports (configured in WinSW XML):
- **Frontend**: 3000
- **Backend**: 5000
- **PostgreSQL**: 5433
- **Redis**: 6379

To change ports, edit:
- `services/UKG-Backend.xml` (Flask port)
- `services/UKG-Frontend.xml` (Next.js port)
- Restart services: `Restart-Service UKG-Backend, UKG-Frontend`

## User Management

### Role Hierarchy

| Role    | Permissions                                          |
|---------|------------------------------------------------------|
| Owner   | Full system access, ownership transfer, all admin   |
| Admin   | User management, configuration, auditing             |
| User    | Knowledge graph, simulations, personal data          |
| Viewer  | Read-only access to knowledge and analytics          |

### Adding Windows Users

When a new Windows user logs in:
1. System detects new SID
2. Auto-registers as `user` role (not `owner`)
3. Username deconfliction applies (e.g., `john` → `john_1`)
4. Separate DPAPI-encrypted profile created

### Promoting Users

As **Owner**, navigate to:
1. **Admin Panel** → **User Management**
2. Select user
3. Change role (admin/user/viewer)
4. Action is **audit logged** with Windows SID

### Transferring Ownership

> [!CAUTION]
> Ownership transfer is **permanent** and requires explicit confirmation.

1. Navigate to **Admin Panel** → **Ownership Transfer**
2. Select target user (must be existing admin or user)
3. Type `TRANSFER` to confirm
4. Current owner becomes `admin`, target becomes `owner`

## Data Management

### Backup & Restore

**Automatic Backups**:
- Nightly at 2:00 AM via Windows Task Scheduler
- 7-day retention policy
- Location: `C:\ProgramData\DataLogicEngine\backups\`

**Manual Backup**:
```powershell
.\backup_data.ps1
```

**Restore from Backup**:
```powershell
# Stop services
Stop-Service UKG-Backend, UKG-Frontend

# Restore database
pg_restore -U ukg_app -d ukg_local C:\ProgramData\DataLogicEngine\backups\ukg_backup_YYYYMMDD_HHMMSS.dump

# Restart services
Start-Service UKG-Backend, UKG-Frontend
```

### Data Residency

**Database Data** (Shared):
- Knowledge graphs
- Simulations
- Audit logs
- User accounts

**Per-User Data** (DPAPI-Encrypted):
- LLM API keys (`HKEY_CURRENT_USER\Software\DataLogicEngine`)
- User preferences
- Linked to Windows SID, **not** in database

## Troubleshooting

### Services Won't Start

**Check logs**:
```powershell
Get-Content "C:\Program Files\DataLogicEngine\logs\backend.log" -Tail 50
Get-Content "C:\Program Files\DataLogicEngine\logs\frontend.log" -Tail 50
```

**Common issues**:
- Port conflict: Change ports in WinSW XML
- Database connection: Verify PostgreSQL service running
- Permissions: Ensure service accounts have read access

### First User Not Owner

**Symptom**: Second user on machine becomes owner

**Cause**: Database was reset after first installation

**Fix**:
```powershell
# Connect to database
psql -U ukg_app -h localhost -p 5433 -d ukg_local

# Check user count and roles
SELECT username, role, windows_sid FROM users ORDER BY created_at;

# Manual role update (if needed)
UPDATE users SET role = 'owner' WHERE windows_sid = 'S-1-5-21-...';
```

See [CROSS_USER_TESTING.md](./CROSS_USER_TESTING.md) for validation checklist.

## Uninstallation

```powershell
cd C:\Program Files\DataLogicEngine\scripts\windows
.\uninstall.ps1
```

**Interactive prompts**:
1. Keep local database? (Y/N)
2. Keep backups? (Y/N)
3. Keep user settings? (Y/N)

**What's removed**:
- Windows services (UKG-*)
- PostgreSQL instance (if selected)
- Application files
- Scheduled tasks

**What's preserved** (by default):
- Backups in `C:\ProgramData\DataLogicEngine\backups`
- User DPAPI credentials in registry

## Security Considerations

### Audit Logging

All sensitive actions are logged to:
- **File**: `C:\ProgramData\DataLogicEngine\logs\audit.log`
- **Database**: `audit_logs` table

**Logged actions**:
- User registration (with Windows SID)
- Role changes
- Ownership transfers
- Profile deletions
- Configuration changes

**Query audit logs**:
```sql
SELECT timestamp, action, windows_sid, details 
FROM audit_logs 
WHERE action IN ('ROLE_UPDATE', 'OWNER_PROMOTED', 'PROFILE_WIPE')
ORDER BY timestamp DESC;
```

### Encryption

**KEK/DEK Pattern**:
- Key Encryption Key (KEK): Derived from `ENCRYPTION_KEK_SECRET`
- Data Encryption Keys (DEK): Rotated every 90 days
- User data encrypted with current DEK

**DPAPI for LLM Keys**:
- Windows SID-linked encryption
- Keys stored in Windows Credential Manager
- Not accessible by other Windows users

|--------------|-------------------------------------------------------|
| Backend      | `C:\Program Files\DataLogicEngine\logs\backend.log`  |
| Frontend     | `C:\Program Files\DataLogicEngine\logs\frontend.log` |

### Health Checks

```powershell
# Service status
Get-Service UKG-* | Select Name, Status

# Database connectivity
psql -U ukg_app -h localhost -p 5433 -d ukg_local -c "SELECT version();"

# API health
Invoke-WebRequest -Uri http://localhost:5000/api/v1/health
```

### Updates

To update the application:
1. Stop services: `Stop-Service UKG-Backend, UKG-Frontend`
2. Backup database: `.\backup_data.ps1`
3. Replace files in `C:\Program Files\DataLogicEngine`
4. Run migrations: `flask db upgrade`
5. Restart services: `Start-Service UKG-Backend, UKG-Frontend`

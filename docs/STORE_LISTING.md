## App Name
DataLogicEngine: Enterprise Knowledge Graph

## Short Description (250 chars)
A secure, cloud-hosted knowledge synthesis engine. Connects disjointed enterprise data into a unified graph for deep reasoning and analysis, powered by advanced AI models.

## Description
**DataLogicEngine** is an advanced knowledge synthesis platform designed for enterprise environments. It transforms isolated datasets into a unified, interactive Knowledge Graph, enabling deep reasoning and complex problem-solving.

### Key Features
*   **Unified Knowledge Graph**: Ingests and links data from CSV, JSON, and Databases into a single navigable graph structure.
*   **Deep Reasoning**: Utilizes advanced cloud-based AI (OpenAI, Azure, Anthropic) to answer complex, multi-hop queries about your data.
*   **Enterprise Security**: Built with "Zero Retention" architecture—your data is processed securely without being used to train public models.
*   **Adversarial Shields**: Includes the KA-61 Input Shield to detect and block prompt injection attacks and malicious queries.
*   **Transparency First**: Clear labeling of all AI-generated content with integrated "Truth Engine" verification layers.
*   **Full User Control**: Manage your data rights with built-in export/delete functionality and granular AI provider selection.

### Cloud Dependency Disclosure
**Important**: This application requires a continuous internet connection to function. All reasoning and knowledge processing are performed securely in the cloud using enterprise-grade providers (OpenAI, Microsoft Azure, Anthropic). No data is processed locally on your device.

### Privacy & Data Handling
We respect your data sovereignty.
*   **Encryption**: All data in transit is encrypted via TLS 1.3.
*   **No Training**: Your queries are never used to train our AI models.
*   **User Rights**: Full GDPR-compliant data export and deletion controls are available directly within the Settings menu.
